# egen-maskin

Automasjon mot din bruker på din PC. Ingen passord her.

Katalog-id i denne kategorien:

- `sandwich-sudo`
- `git-panic`
- `hacker-movie`
- `love-omarchy`

Hver av dem åpner foot med Super+1 og skriver harmløse `echo`- eller `git`-linjer. Skissene ligger i `../../sketches/<id>/`. Flash med `tools/flash.sh <id>`.
