# demo

Harmløse tester. Bruk i en tom teksteditor (ikke i terminal med sudo).

`demo-hello` er en håndskrevet sketch og står ikke i katalogen.

Katalog-id i denne kategorien:

- `matrix-hello`
- `cowsay-chaos`
- `fortune-bomb`
- `disco-ascii`
- `keyboard-cat`
- `coffee-break`
- `countdown-jk`
- `party-parrot`

Skissene ligger i `../../sketches/<id>/`. Flash med `tools/flash.sh <id>`. Tabellen står i `../../docs/TOP20.md`.
