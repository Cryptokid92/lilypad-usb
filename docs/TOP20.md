# De 20 payloadene

`catalog.json` er kilden. Kjør `python3 tools/generate_sketches.py` for å skrive `sketches/<id>/<id>.ino` på nytt.

Demo-radene skriver i vinduet som allerede har fokus. De andre åpner foot med Super+1 og skriver deretter.

Tegn utenom bokstaver, tall og mellomrom sendes som US-tastaturkoder. Norsk tastaturoppsett kan vise et annet tegn for kolon, skråstrek, pipe og bindestrek.
